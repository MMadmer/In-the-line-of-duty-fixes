## RU

## Тема

Задание «Ремонт научного детектора», вылет при взаимодействии из 1.0.10 и панель в X18

## Изменения

* Установлена версия 1.0.5, 1.0.6 или 1.0.7? Обновление из игры невозможно (ошибки 21 и 2). Распакуйте полный архив Setup_Manual в корень игры один раз, далее обновления устанавливаются автоматически.
* Исправлен вылет при взаимодействии с дверями и ящиками, появившийся в 1.0.10. Хотфикс с форума больше не требуется.
* Задание «Ремонт научного детектора»: микросхема появляется всегда, метка задания указывает на неё.
* Задание о шпионах Ребы больше не оставляет игрока без интерфейса и управления.
* Кнопочная панель в X18 переключается корректно; сбитые ранее панели возвращаются в исходное состояние.
* Сейф в тоннеле открывается после ввода кода.
* Задание с Игрушечником: любой исход больше не блокирует дальнейшее прохождение.
* Из лагеря нацистов убран неуязвимый NPC, добавленный в 1.0.8; диалог с Карабином снова доступен.
* ОЦ-33 «Пернач» больше не вызывает вылет при стрельбе.
* «Крысиный король» больше не расходуется клавишей аптечки.
* Замки, открытые ключом или отмычкой, запоминаются корректно на всех уровнях; кодовые замки не переключаются при повторном использовании.
* Необязательные задания Волка корректно завершаются по ходу сюжета.
* КПК Закорпата: порядок передачи и связанные диалоги исправлены.
* Юра больше не сбивается со своего этапа задания.
* Метка тайника Лёхи Говорящего снимается, когда тайник опустошён.
* Сцены построения в Баре и речи командира эсэсовцев больше не обрываются.
* Поручение Сахарова про костюм «Монолита» больше не вызывает вылет.
* Прибор в депо Свалки: второй прыжок работает как первый.
* Кузьма: диалог с братом доступен и в сохранениях, сделанных до 1.0.9.
* Пси-кейс Толика не вызывает вылет в старых сохранениях; голоса на ЖД-мосту затихают вовремя.
* База на Агропроме: доступ на третий этаж больше не может заблокироваться.
* Тайники Искателя выдаются в правильные ящики; добавлены недостающие фары для ремонта машин.
* Костюм курьера больше не изнашивается ускоренно; изношенный до обновления костюм один раз восстанавливается до 100%.
* Нива на автопарке Бара: детали не списываются повторно после ремонта.
* Скриптовое удаление объектов на Кордоне больше не затрагивает объекты на других уровнях.
* Скриптовые NPC в Баре, Тёмной долине, на Складах и в финале больше не уходят в лагеря.
* Люк вышки на Агропроме открывается, если ключ был потрачен до 1.0.10.
* Подсказки в депо и тюрьме срабатывают только в нужном месте.
* Исправлены тексты: подпись пояса, описания переделанных стволов и Karabin-98, реплики механика и Эконома.
* Обновлятор: устойчивость к лимитам GitHub API, версия и результат проверки в главном меню; патч без базы не роняет игру.
* Обновление не отказывает кодами 26 и 27 после ручного отката или изменения скриптов.

## Установка

Распакуйте архив In-the-line-of-duty-fixes-1.0.11-Setup_Manual.zip в корень игры. Ни один оригинальный файл игры или мода не заменяется, сохранения остаются рабочими. Аддон можно удалить в любой момент по списку `.ild-fixes/managed-files.txt`. Update_Patch содержит только изменения относительно 1.0.10, устанавливается поверх 1.0.10 встроенным обновлятором и не требует ручной распаковки. Версии 1.0.5–1.0.7 обновляются только ручной распаковкой полного архива.

## EN

## Theme

The "Repair the scientific detector" task, the interaction crash of 1.0.10 and the X18 panel

## Changes

* Running 1.0.5, 1.0.6 or 1.0.7? The in-game update cannot install (errors 21 and 2). Unpack the full Setup_Manual archive into the game root once; updates install automatically from then on.
* The crash on interacting with doors and boxes introduced in 1.0.10 is fixed. The forum hotfix is no longer needed.
* "Repair the scientific detector": the chip always appears and the task marker points to it.
* Reba's spies task no longer leaves the player without HUD and controls.
* The button panel in X18 switches correctly; panels scrambled earlier return to their initial state.
* The safe in the tunnel opens after the code is entered.
* The Toymaker task: no outcome blocks further progress.
* The invulnerable NPC added to the nationalist camp in 1.0.8 is removed; the dialog with Karabin is available again.
* The OC-33 "Pernach" no longer crashes the game when fired.
* The Rat King is no longer consumed by the medkit key.
* Locks opened with a key or a lockpick are remembered correctly on every level; code locks no longer toggle on repeated use.
* Volk's optional tasks complete correctly as the story progresses.
* Zakorpat's PDA: the hand-over order and the related dialogs are fixed.
* Yura no longer loses his current task stage.
* The marker of Lyokha the Talker's stash is removed once the stash is emptied.
* The Bar formation scene and the SS commander's speech are no longer cut short.
* Sakharov's Monolith suit errand no longer crashes the game.
* The device in the Garbage depot: the second jump works like the first.
* Kuzma: the dialog with his brother is available in saves made before 1.0.9 as well.
* Tolik's psi case no longer crashes old saves; the voices on the railway bridge stop in time.
* The Agroprom base: access to the third floor can no longer be blocked.
* The Seeker's stashes go to the right boxes; the missing headlights for car repairs are added.
* The courier suit no longer wears out prematurely; a suit worn down before the update is restored to 100% once.
* The Niva at the Bar car park: parts are not taken a second time after the repair.
* Scripted object removal on the Cordon no longer affects objects on other levels.
* Scripted NPCs in the Bar, Dark Valley, the Army Warehouses and the finale no longer leave for camps.
* The Agroprom tower hatch opens if its key was spent before 1.0.10.
* The depot and prison hints trigger only in their place.
* Texts fixed: the belt caption, the descriptions of the re-chambered guns and the Karabin-98, the mechanic's and Ekonom's lines.
* Updater: resilient to GitHub API limits, the version and check result in the main menu; a patch without its base no longer crashes the game.
* Updates are no longer refused with codes 26 and 27 after a manual rollback or edited scripts.

## Installation

Extract In-the-line-of-duty-fixes-1.0.11-Setup_Manual.zip into the game root. No original game or mod file is replaced and existing saves keep working. The addon can be removed at any time using `.ild-fixes/managed-files.txt`. Update_Patch carries only the changes since 1.0.10, is applied over 1.0.10 by the in-game updater and needs no manual unpacking. Versions 1.0.5–1.0.7 update only by unpacking the full archive by hand.
